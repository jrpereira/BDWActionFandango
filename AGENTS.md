# Action Fandango development

In the Gaming workspace, read the shared `RULES.md` and relevant procedures before
working on this module. Keep runtime source in `Scripts/`, tests
in `tests/`, tooling in `tools/`, and public documentation in `docs/`.

Do not infer gameplay behavior from the project name. Confirm the requested
player actions and acceptance criteria before implementing a runtime. Preserve
personal configuration and enablement during installation. Keep credentials,
diagnostics, and private coordination records outside the public repository.

The module Owner handles implementation, tests, Git, and installation. Coordinate
cross-module interfaces and overlapping installations with the Coordinator.
